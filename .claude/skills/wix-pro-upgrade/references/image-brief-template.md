# Image brief template for `banana`

Fill this once per site from the step-0 brand capture, then reuse it for every image so the set looks like one photographer shot it.

```
BRAND DIRECTION (fixed for the whole site)
Business: <what they do, for whom>
Mood: <e.g. calm, premium, warm, clinical, energetic>
Palette: <2–3 hex values + neutrals>
Photography style: <e.g. natural window light, shallow depth of field, muted warm grade, no HDR>
Never: <e.g. stock-photo handshakes, fake smiles, text baked into image, watermarks, people unless real>

THIS IMAGE
Purpose: <hero | section banner | product shot | service card | team placeholder | favicon | OG share image>
Placement: <page / section, and the container aspect ratio, e.g. 16:9 hero, 1:1 card, 1200×630 OG>
Subject: <exactly what is in frame>
Composition: <where the empty space goes so headline text can sit over it>
Output: <aspect ratio> · <size 2K/4K> · <format>
```

## Standard sizes
| Use | Aspect | Size |
|---|---|---|
| Hero (desktop) | 16:9 or 21:9 | 4K |
| Section banner | 3:1 | 2K |
| Service / product card | 1:1 or 4:5 | 2K |
| Blog cover | 16:9 | 2K |
| OG / social share | 1.91:1 (1200×630) | 2K |
| Favicon source | 1:1 | 1K, simple mark, works at 32 px |

## Rules
- Generate → show the owner → approve → `UploadImageToWixSite`. Never upload unseen.
- Keep one seed style; regenerate off the first approved image with `banana edit` when a matching variant is needed.
- Real people, real premises and real products beat generated ones. Ask the owner for photos first; generate only to fill genuine gaps, and label generated people-free (interiors, objects, abstracts) unless the owner explicitly wants illustrative figures.
- Add alt text at upload time: what the image shows + why it's there, ≤ 125 characters.
